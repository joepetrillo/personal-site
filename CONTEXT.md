# Personal Site

Language for Joe Petrillo's personal site. This glossary keeps public-facing content concepts consistent as the site evolves.

## Language

**Writing**:
Authored pieces on the site, including technical posts, travel notes, learning notes, and other things worth sharing.
_Avoid_: Blog, articles, posts as the section name

**RSS Feed**:
The public syndication feed for Writing entries only.
_Avoid_: Site feed, project feed, links feed

**Projects**:
Public things Joe personally built or materially shaped, listed with a one-line note and clear external destinations such as GitHub or live links.
_Avoid_: Portfolio, case studies, project writeups, work history

**Links**:
A small, curated list of external things worth sharing, presented by newest-added first without behaving like a high-volume feed.
_Avoid_: Bookmarks, resources, link blog

**Selected Timeline**:
A small set of chosen life, career, learning, or project moments that explain progression and direction without serving as a complete biography or work history.
_Avoid_: Resume timeline, work history, chronology

**Personal Overview**:
The opening homepage area that combines Joe's name, restrained avatar, primary intro copy, and quiet links with human and professional context.
_Avoid_: About page, hero plus about, bio, autobiography

**Primary Sans**:
Switzer, the self-hosted sans font used for nearly all interface and reading text.
_Avoid_: Brand font, display font

**Handwritten Accent**:
Comico, the self-hosted handwritten display font used only in a few restrained moments where a personal accent is useful.
_Avoid_: Heading system, body font, decorative theme
